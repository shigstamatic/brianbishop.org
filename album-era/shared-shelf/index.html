Open the original link

Shared shelf links are handled by Album Era on supported iPhone and iPad devices. Open the original link from the message or email where you received it. Installing Album Era after opening this page does not automatically resume the import.

Import the attached file

If the link does not open Album Era, use the attached JSON file instead. In Album Era, open Organize Shelves and import the shared shelf file from there.

Need Album Era?

Album Era is free on the App Store for iPhone and iPad. Apple Music playback and catalog search require a separate active Apple Music subscription.
