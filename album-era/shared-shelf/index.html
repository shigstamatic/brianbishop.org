Shared shelf

Open this shelf in Album Era.

Importing shared shelves requires Album Era 1.1 or later on an iPhone or iPad. Earlier versions do not support shared shelf imports.

Open the original link

Open the original shared link on your iPhone or iPad with Album Era 1.1 or later installed. After installing or updating, return to the original message or email and tap its link again. Installation does not automatically resume an import.

If you received a JSON file

If you received a JSON file instead of a link, save it to Files. Then open Album Era 1.1 or later, choose Organize Shelves, and tap Import. A shared link does not also include a JSON attachment.

Need Album Era?

Album Era is free on the App Store for iPhone and iPad. Check that version 1.1 or later is available before using shared shelf imports. Apple Music playback and catalog search require a separate active Apple Music subscription.
